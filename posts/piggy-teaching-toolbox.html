AI 教学视频多模态素材生成平台

做一个教学视频的素材准备工作很碎：写脚本、找图、配音、做字幕，每步换一个工具， 中间结果还接不上。这个平台把这条链路收进一个向导——输入主题、受众与知识点， 导出分镜脚本、场景图、中英双语配音、SRT 字幕和一份归档清单。

六步工作流

一个项目从主题出发，先由模型展开为 5–20 个结构化分镜，随后逐镜补齐脚本、 图像与视频 Prompt、场景图、中英旁白、双语音频、字幕，最终打包成素材包。 内置教学、儿歌、绘本/故事、朗诵四类预设风格，外加自定义风格。

每一步都是显式阶段而不是黑盒：阶段产物落库，用户可以在任意一步停下来检查、修改， 再继续往下走。

两阶段结构化生成

一次性让模型输出完整分镜 JSON，最常见的失败是长输出被截断，或者后半段字段漂移。 这里改成 大纲生成 → 逐镜补全 两阶段：

  • 第一阶段只产出分镜骨架与叙事走向，输出短、结构稳定。
  • 第二阶段逐镜补全，每次调用都携带前后文，保持叙事连贯而不是逐镜孤立。
  • 输出侧做 JSON 容错解析、时长归一、角色 ID 过滤，再过 Pydantic 参数校验。
角色 ID 过滤 模型会在旁白里自由发挥出不存在的角色名。用已登记的角色 ID 集合做一次过滤， 把幻觉实体挡在素材生成之前，比事后重做整段配音便宜得多。

跨分镜的角色一致性

图像侧接入 Seedream 的文生图与参考图生图：按角色 ID 复用最多 3 张参考图， 让同一个角色在不同场景里外观稳定。单镜支持重生成，不影响其他分镜。

分镜内容、Prompt 与资源状态都保留人工编辑入口——生成质量再稳定也需要人来收尾， 所以流程按 Human-in-the-loop 设计，而不是「一键出片」。

音频与字幕

配音用 IndexTTS 生成中英文分镜音频，支持多种情感与语速/音量/情感强度调节， 随后合并为整轨音频；字幕按分镜时间轴动态生成双语 SRT。 分镜生成阶段会同时推荐情感与音频参数，用户可手动覆盖。

任务可靠性与交付

项目、分镜、角色与资源状态全部持久化在 MySQL，中间产物归档到腾讯云 COS， ZIP 打包由 SCF 云函数按需完成。异步侧用 task_id 做进度轮询， 并用 active task 校验拦截同一项目的重复提交。

关注点做法
断点续跑阶段状态落库，从任意阶段恢复而不重跑全链
重复提交提交前检查该项目是否已有进行中任务
进度可见task_id 轮询，返回阶段与失败原因
产物归档图片、音频、Prompt、字幕与 Manifest 一并入 COS
