W-01 2025.09 – 2026.04 Agent 应用开发

军考方向的 AI Agent 学习平台

面向备考的 Agent 平台。开放式问答走统一的 EduAgent，业务指定的能力按 Skill 装载， 多轮会话和已激活能力用 Checkpointer 保存。我做 Agent 编排、三层记忆（会话状态 / 长期记忆 / 用户画像）、RAG 检索和主观题批改链路，也把 PHP 侧的 AI 能力迁到 Python 服务。

长任务用 AnyIO + Taskiq 承载，Dishka 统一 API、gRPC 和 Worker 的依赖生命周期； 有进度追踪、取消、失败重试和宕机恢复，再用 MySQL / Redis 定时对账兜底。 批改侧给视觉模型加了 URL 并发校验、30/45s 超时和备用模型重试，证据不足时输出可解释的异常状态而不是硬给分。

W-02 2024.07 – 2025.08 PHP 后端

英语听说 App 与题库内容平台

个人版 App 的后端：作业、学习卡、自主练习走 ThinkPHP + Swoole + gRPC 微服务， 另外接了 AI 口语家教和作文评测。题库这边负责新增题型从数据模型、API、录入页到 数据同步的整条链路，也优化了教材题目和试卷的批量导入脚本。

用 Coze 搭英语近似词工作流，配合资源库缓存和批量处理压掉重复的模型调用； Elasticsearch 分担 MySQL 的检索压力，题目语音走 Azure TTS。 题目解析封装成 Composer 公共包给其他服务复用，链路上接入 OpenTelemetry / Jaeger、 HAProxy 负载均衡，交付走 Jenkins + Docker。
